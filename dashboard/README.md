# Tower Time-Lapse Dashboard

Phase 10 dashboard foundation.

## Run

```powershell
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5173
```

Backend default:

```text
http://127.0.0.1:8000/api/v1
```

To change it create `.env`:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
```

## Pages

- Dashboard
- Cameras
- Snapshots
- Time-Lapses
- Settings

Phase 10 focuses on layout, navigation, API connectivity, and read-only system overview.
